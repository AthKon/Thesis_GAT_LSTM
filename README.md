# GAT-LSTM Mooring Line Load-Field Surrogate

Graph-attention LSTM (GATv2 + per-node LSTM) surrogate model for predicting mooring-line
motion and tension fields from finite-element simulation data, developed for my MSc thesis
in Offshore and Dredging Engineering at TU Delft.

A mooring line is represented as a chain graph. A two-layer GATv2 encoder captures spatial
coupling between neighbouring nodes, a per-node LSTM encoder captures each node's temporal
evolution, and a compact MLP head returns the future motion and tension of the whole line
in one non-autoregressive pass. One trained set of weights is used across mooring-line
discretisations from N = 4 to N = 21 nodes and ten offshore locations, two of which are
held out to test generalisation.

## Notebooks

### `GAT_LSTM_NN.ipynb` — primary model (fixed-weight loss)

The defended model. Trains the GAT-LSTM architecture under a fixed-weight objective: a
SmoothL1 data loss plus four hand-tuned physical penalty terms (accuracy on the physical
targets, peak-tension accuracy, an asymmetric underprediction penalty that biases the model
toward safe overprediction of peak loads, and temporal smoothness). This is the thesis's
headline result: a global tension $R^2$ of 0.98, with test accuracy meeting or exceeding
validation accuracy at every node count.

### `GAT_LSTM_NN_C2.ipynb` — uncertainty-weighted variant (Kendall)

Same architecture and data pipeline, different training objective. Replaces the four
hand-tuned physical weights with a Kendall multi-task uncertainty-weighting scheme, which
learns a per-term weight automatically from the model's own fit quality during training.
The notebook also documents a failure mode found along the way (the learned weight on the
one-sided underprediction penalty diverges) and its fix (reformulating that term as a
two-sided quantile/pinball loss). Included as a contribution in its own right: a safety-aware
training methodology, together with the diagnosis of where the naive version breaks.

## Data

These notebooks expect a cache of finite-element mooring simulations (motion, tension and
contact time series for ten offshore locations) that is not included in this repository.
The simulation data was generated by Shagun Agarwal's geometrically nonlinear finite-element
mooring model and is not currently public. The notebooks are shared here for methodological
reference and to accompany the thesis; they are not intended to run end-to-end without
access to that dataset.

## Reference
